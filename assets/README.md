```text
assets/
```

## Quy tac

- Logo & branding -> `assets/images/`
- Mobile-specific assets (app icon, splash, adaptive icon) -> `apps/mobile/assets/`
- Neu co ban SVG chinh thuc thi uu tien SVG; hien tai project dang su dung bo PNG duoc cung cap.
